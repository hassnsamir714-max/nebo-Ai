نبو (Nebo) نموذج تعليمي صغير لتوليد النصوص باللغة العربية، مكتوب بـ Python وPyTorch. يتعلّم النموذج توقّع الحرف التالي باستخدام شبكة Transformer سببية صغيرة، ثم يولّد النص حرفاً بعد حرف. الأوزان تُدرّب محلياً من بيانات المشروع؛ لا يحتاج إلى API أو مفتاح سري.

> «من الصفر» هنا يعني أن بنية النموذج وكود التدريب مكتوبان لهذا المشروع، لا أن النموذج ينافس النماذج التجارية الضخمة. نموذج حرفي صغير يحتاج بيانات كثيرة ومتنوعة ليعطي إجابات جيدة.

## محتويات المشروع
- `model.py` — طبقات Transformer سببية وتوليد الحروف باستخدام PyTorch.
- `train.py` — تدريب النموذج وحفظ الأوزان في `nebo_model.pt`.
- `app.py` — واجهة محادثة محلية باستخدام Streamlit.
- `data/sample_data.txt` — نص عربي تجريبي للتدريب.
- `requirements-dev.txt` — الاعتمادات؛ المستودع يحتوي مسبقاً على مجلد باسم `requirements.txt` لذلك لا يمكن إنشاء ملف بهذا الاسم في الجذر.

## التشغيل
يتطلب Python 3.10 أو أحدث. من مجلد المشروع:

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell
# .venv\\Scripts\\Activate.ps1

python -m pip install -r requirements-dev.txt
python train.py --steps 1000
streamlit run app.py
```

يمكن استخدام `--steps 2000` أو أكثر لتحسين التعلّم، مع الانتباه إلى أن التدريب على CPU قد يستغرق وقتاً. استخدم `python train.py --help` لعرض الخيارات، مثل `--device cuda` عند توفر GPU متوافق.

## تخصيص بيانات التدريب
أضف نصوصاً عربية أو عراقية مرخّصة تملك حق استخدامها إلى `data/sample_data.txt`، ثم أعد تشغيل التدريب. كلما كانت البيانات أكبر وأكثر تنوعاً، كان التعلّم أفضل. احفظ النص بصيغة UTF-8. النموذج يتعلم الأنماط الموجودة في النص فقط، وليس لديه اتصال بالإنترنت أو معرفة خارج بيانات التدريب.

## ملاحظات
- لا ترفع ملف `nebo_model.pt` إلى Git؛ يمكن إعادة إنتاجه بتشغيل التدريب.
- مخرجات النموذج التجريبي قد تكون غير مترابطة، خصوصاً مع مجموعة البيانات الصغيرة المرفقة.
